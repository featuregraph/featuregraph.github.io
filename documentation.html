Getting started

FeatureGraph converts grouped observation sequences into explicit behavioral objects. The 0.2 beta candidate includes rising, falling, and inactive transitions; oscillations composed from those transitions; wave-derived accumulation; optional irregular-time measurement; explicit parent identity; inspectable feature and object tables; and deterministic queries.

Installation

pip install featuregraph

The archived alpha is available now. Version 0.2.0b1 has passed local release verification and will be installable after its prerelease tag and archive are published.

Object-level queries

Queries operate on constructed object tables instead of rediscovering boundaries and measurements. This separates deterministic construction from downstream consumer layers and keeps results inspectable.

result = fg.query(
    oscillation_objects,
    duration={"gt": 120},
    is_complete=True,
)

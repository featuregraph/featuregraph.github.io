Install the released alpha

python -m pip install "featuregraph @ git+https://github.com/featuregraph/featuregraph.git@v0.1.0a1"

For alpha-compatible development, clone alpha/v0.1.x. Do not install from main expecting alpha examples to run.

Alpha capabilities

FeatureGraph v0.1.0a1 provides explicit oscillation objects, wave-derived accumulation objects, retained construction features, object summaries, deterministic querying, BIDMC and Tennessee Eastman loaders, and a reproducibility package.

Read the tagged alpha documentation →

Development line

The main branch is redesigning construction around transition summaries and revising how higher-order behaviors consume them. The interface is incomplete and may change without migration support. Development documentation describes this work, not released functionality.

Research evidence

The alpha notebooks, evaluation files, Zenodo record, and published results are tied to v0.1.0a1. A future evaluation of the successor architecture will be versioned separately rather than overwriting that evidence.

Getting started

FeatureGraph converts grouped observation sequences into explicit behavioral objects. The public alpha includes oscillation construction, wave-derived accumulation, dataset loaders, inspectable intermediate features, object tables, and a deterministic query layer.

Installation

pip install featuregraph

The alpha release is also available from the public GitHub repository and is archived with the associated reproducibility materials on Zenodo.

Object-level queries

Queries operate on constructed object tables instead of rediscovering boundaries and measurements. This separates deterministic construction from downstream consumer layers and keeps results inspectable.

result = fg.query(
    oscillation_objects,
    duration={"gt": 120},
    is_complete=True,
)

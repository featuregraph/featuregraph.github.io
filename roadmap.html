Roadmap

From a verified beta representation to a behavioral reasoning layer.

The roadmap prioritizes semantic precision, reproducibility, and practical demonstrations before expanding the framework’s behavioral vocabulary and execution backend.

Completed

Foundation established.

Complete

Behavior lifecycle

A shared construction interface for signals, primitives, identifiers, features, summaries, and queries.

Complete

Oscillation objects

Explicit boundaries, measurements, completeness, object tables, and cross-domain demonstrations.

Complete

Transition composition

Rising, falling, and inactive objects now provide the shared directional layer used by Oscillation without changing Accumulation’s outward contract.

Complete

Alpha release

Public repository, automated tests, dataset loaders, reproducibility package, GitHub release, and Zenodo archive.

Complete

Beta candidate

Authoritative semantics, time-aware construction, explicit parent identity, held-out evaluation, 91 tests, executable notebooks, and clean packages.

Current work

Use the completed initial chain and gather stronger evidence.

Priority 01

Real-data validation

Extend the completed synthetic comparison with expert or independently derived boundaries on physiological and industrial signals.

Priority 02

Manuscript alignment

Align the formal specification, implementation, tests, examples, and paper language around one authoritative Transition → Oscillation → Accumulation definition.

Priority 03

Beta feedback

Exercise the stable schemas and time-aware API in external workflows, then make evidence-driven refinements before a release candidate.

Priority 04

Consumer demonstration

Build a small non-linguistic layer that consumes the query interface and clearly demonstrates what FeatureGraph exposes without hiding construction behind natural language.

Research validation

Prepare the first paper.

Boundary validation

Evaluate whether constructed objects correspond to observable cycles, including manual annotation, incomplete boundaries, noise sensitivity, and smoothing sensitivity.

Cross-domain consistency

Demonstrate that BIDMC and Tennessee Eastman produce the same object schema through the same mathematical construction procedure.

Reproducible evidence

Generate final tables, figures, manifests, benchmark records, and archived artifacts directly from release scripts.

Paper preparation

Align the formal specification, implementation, tests, documentation, and manuscript so they share one authoritative definition of each behavior.

Longer horizon

A tensor-based behavioral representation layer.

Future

Tensor backend

Move validated construction mathematics from the Pandas prototype to vectorized tensor execution, likely using PyTorch.

Future

Extensible behavior API

Allow software agents and researchers to define new behavioral objects from explicit states, events, relations, and measurements.

Future

Behavioral archetypes

Explore transport, growth and decay, switching, interaction, and other recurring dynamic structures after the initial semantics stabilize.

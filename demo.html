Demonstration

Asking questions of a table, with every answer checkable.

A language model translates a plain-English question into a short query. It never sees the data and never does arithmetic. A separate program checks the query, runs it on the table, and returns the answer. Every run is saved as a receipt: the question, the model's reply, the query, the answer, and fingerprints of the prompt, the table and the code.

What this is: a demonstration on a small made-up table of breathing recordings, recorded once. It is not a measurement of accuracy. Questions written in advance and a held-out test come next.

When Cohere's API returned an empty response, the call was retried, up to three attempts. Nothing else was retried or edited.

One limit, stated plainly: a well-formed query that means something other than what was asked passes every check. The sentence beside each answer, the query written back in plain English, is how a person catches it.

How to read the colors

  • Green, answered. The request passed every check and ran.
  • Purple, refused. The request was valid, but the answer is not unique, for example a tie. The system does not pick one.
  • Amber, declined. The model said the question cannot be asked with the operations available.
  • Red, rejected. The request was stopped before anything ran, because the reply was not a valid query or it named a dataset that is not in the table. Red says which check stopped it, not whose fault it was.

None of these is a score. A request that passes every check can still mean something other than what was asked.

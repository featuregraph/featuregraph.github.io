FeatureGraph: one-page summary

What it is

The coding tool built for data science. For scientific and engineering time-series data.

FeatureGraph is a coding tool designed for data science teams. As companies increasingly adopt AI coding for data scientists, there is a growing need for infrastructure and data tools specifically designed for this.

The problem

There is a strong push for data science teams to use AI to write code and move away from coding by hand. However, reliable and trustworthy data analysis cannot be vibe-coded using only general-purpose coding tools.

Why now

The move towards AI-driven coding creates space for an ecosystem of coding tools and assistants. A useful tool adopted early helps make the best use of AI spend.

The product

Specialized tools already exist for software engineering teams, and data analysis layers are already built on top of warehouses like Snowflake.

What differentiates FeatureGraph is that it specifically targets science and engineering time-series analysis, using built-in representations of physical signal structure.

FeatureGraph supplements the AI coding pipeline rather than replacing it, by making the data store available to agents and allowing them to query results rather than having to write the code to derive them.

First customers and the pilot

The first customers are science and engineering teams with time-series data and limited spare analyst capacity, starting with early-stage signal-processing companies.

The first offer is a fixed-fee pilot of three to four weeks from receipt of the customer's historical data. We set up the data and build the store and access points. The customer sends one data extract and a few hours of the data team’s time. Raw customer data is not retained by FeatureGraph after the pilot.

Each setup becomes a reusable template, so the next one takes less work. The pilot price is set by the first pilots.

What is already built

A working compiler, data store, and query layer.

  • featuregraph-core, the compiler, is open source (MIT-licensed beta). The built customer data store and query layer are the commercial product.
  • Studies run in multiple domains: respiratory data from hospital patients, industrial control processes, wearable heart rate signals, and others.
  • A public demo of the question-to-query loop: 13 runs on two language models.
  • A Cohere Labs grant, awarded August 2026.
  • Introductory API demo built for machine learning lab Synthefy.

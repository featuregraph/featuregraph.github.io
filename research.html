Making dynamic behavior explicit.

Research problem

Time series contain behaviors that ordinary sample tables do not expose.

A waveform may visibly contain cycles, transitions, intervals, and accumulated quantities, but those structures are not represented as objects. Each downstream analysis must recover them again, often through domain-specific feature engineering or opaque learned representations.

FeatureGraph asks whether those structures can be constructed once through deterministic rules, stored as explicit objects, and reused by analysis or reasoning systems. The immediate research question is whether the same mathematical construction produces a consistent schema across unrelated physical domains.

Behavioral object framework

A shared construction lifecycle.

Every supported behavior begins with observation sequences and grouping boundaries. Primitive states are derived from those observations, transition events mark meaningful changes, identifiers bind events into objects, and object tables expose intrinsic measurements and relationships.

Behavior 01

Oscillation

The alpha implementation constructs explicit oscillation objects from rising and falling states, peak and trough events, and deterministic object identifiers. An oscillation is represented as a bounded object rather than a loose set of sample-level features.

The current object schema includes start, peak, and end locations; rise and fall durations; total duration; period; amplitude; temporal symmetry; and completeness. Construction features remain inspectable so that the final object can be traced back to the states and events that produced it.

Behavior 02

Accumulation

The current accumulation implementation is wave-derived. It constructs a contribution signal relative to a specified baseline, integrates that contribution within each parent oscillation, and preserves the relationship between the derived object and its parent.

Measurements include total area, area at the peak, time to maximum accumulated area, average accumulation rate, centroid time, peak instantaneous rate, and accumulation before and after the oscillation peak. Parent completeness is propagated so an incomplete oscillation cannot silently produce an apparently complete dependent object.

Reasoning interface

Querying objects instead of rediscovering them.

Once behaviors have been constructed, questions can be asked directly over object tables. Queries can select long oscillations, compare symmetry, filter complete objects, inspect accumulation timing, or relate dependent objects to their parents without repeating the construction process.

The query layer is deterministic and intentionally avoids natural-language interpretation. Its purpose is to expose exactly what FeatureGraph constructed, preserving the distinction between object construction and any later consumer or reasoning layer.

Cross-domain evaluation

BIDMC and Tennessee Eastman.

The initial release applies the same framework to BIDMC respiration waveforms and Tennessee Eastman industrial process signals. These domains differ in sampling context, physical meaning, and signal morphology, while producing the same oscillation object schema and compatible query interface.

The reproducibility package records the software environment, hardware context, dataset loading procedures, and scripts used to generate paper tables and figures. The next stage is to finalize behavioral semantics and complete quantitative validation of object boundaries, robustness, and sensitivity.

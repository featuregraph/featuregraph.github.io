Latest release

v0.1.0a1

The first alpha release establishes explicit behavioral object construction as a working public framework. It captures the implementation used for current oscillation and accumulation research while leaving room for semantic and API refinement.

GitHub releaseZenodo archive

Release scope

  • Alpha implementation of explicit oscillation objects
  • Wave-derived accumulation objects
  • Parent completeness propagation
  • Inspectable construction features and object tables
  • Deterministic query interface
  • BIDMC and Tennessee Eastman dataset loaders
  • Reproducibility script and manifest
  • Environment and hardware capture

Current development

Progress after v0.1.0a1.

The archived alpha remains the citable record of its original oscillation and accumulation implementation. Development since that release adds first-order rising, falling, and inactive Transition objects, composes Oscillation from them, preserves the Accumulation contract, and expands notebooks, CI, tests, and the cross-domain reproduction pipeline across all three layers.

Release meaning

What “alpha” indicates.

Working implementation

The core construction pipeline is operational, tested, documented, and available for external inspection.

Research stability

The release preserves a citable implementation for reproducing current results even as development continues.

Expected refinement

Behavioral semantics, edge-case policy, APIs, and performance may change before the first stable release.

Use FeatureGraph from Claude

Ask questions of FeatureGraph’s public datasets, in plain English.

Connect FeatureGraph to Claude and ask about the respiration recordings in our database. Each answer comes from a checked query run on the data, and comes with a receipt anyone can use to verify it.

What you can ask

Questions about public datasets.

The first datasets are the BIDMC and CapnoBase respiration recordings, already converted to FeatureGraph objects. More will follow. Questions that work well:

  • How many BIDMC subjects have a confident respiration period?
  • List the BIDMC subjects where no reliable period was found.
  • Among confident CapnoBase cases, which are outliers in both the number of detected cycles and mean temporal symmetry?

Connect

Add it once, then just ask.

  1. Request an access key with the form below.
  2. In Claude, add a custom connector. Paste the address [connector address] and your key. The menu names depend on your Claude plan.
  3. Start a chat and ask a question. Claude asks FeatureGraph, and FeatureGraph checks and runs the query.

What you get back

An answer you can check.

Every answer has three parts:

  • The answer, in plain words.
  • The query, written back in plain English, so you can confirm it asked what you meant.
  • A receipt: the question, the query, the answer, and fingerprints of the data and the code. Anyone can open it and rerun it for the same result.

No language model runs inside FeatureGraph. The calculation is done by a program that checks the query first.

Limits

What it does not do.

  • It answers only from the public datasets above. You cannot upload data here.
  • Some questions get a refusal instead of an answer: the result is a tie, the question needs an operation FeatureGraph does not have, or the query names something that is not in the table. You will see which.
  • Claude writes the reply. FeatureGraph guarantees the numbers and the receipt, not the wording around them, so check the restated query.
  • The results describe signal structure. They are not clinical findings.

Want your own data analyzed? Ask for an analysis built on your data.
